A NOTE FROM THE GARDEN

Space is busy.
We made it a little softer.

This illustrative view is not a precise orbit simulator or collision warning system.

The app runs on a small, fixed sample of familiar satellite and debris names held in sample-data.js. Marker positions, altitudes and counts are decorative: real orbital data changes constantly, and this view never calculates trajectories, proximity or collision risk. No collision predictions or risk scores are shown anywhere.

When run locally, reports can be written by an open-weight model through Ollama. If the local model is unavailable, a clearly labelled sample report keeps the garden in bloom.

LOCAL MODEL llama3.2:3b set with OLLAMA_MODEL
